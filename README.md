## Project Overview

Marvel Character Gallery is a full-stack web application developed using Java, Spring Boot, FreeMarker, Spring Data JPA, and PostgreSQL.

This project extends Assignment 3 by connecting a dynamic frontend to the existing Marvel Character REST API and Neon PostgreSQL database.

Users can browse Marvel characters, search and filter characters, view detailed profiles, add new characters, edit existing characters, and delete characters.

The application is deployed to Render using Docker.
